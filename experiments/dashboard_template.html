When carbon forecasts are wrong

Carbon per run as forecast error grows. Temporal Green trusts the forecast blindly; GreenOps re-plans every hour and degrades less. From 30 % error onward it is the greener of the two.

How long is it worth waiting?

Carbon per run against the longest allowed delay. Almost all of GreenOps' gain arrives within 2 hours; longer waits mostly add latency.

Data. Germany and Norway: Energy-Charts generation mix with IPCC AR5 emission factors. India: modelled from CEA figures. Forecast error calibrated on National Grid ESO forecasts. Prices, power and PUE are representative assumptions.

Method. Discrete-event simulation (SimPy). Comparison values are means over 20 random seeds per season; the replay is one run. Regenerate with python -m experiments.build_dashboard.
